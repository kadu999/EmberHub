## Default Permission

EmberHub Android Intent 插件默认权限（启动目标 App 并传入 ROM）

#### This default permission set includes the following:

- `allow-launch`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`android-intent:allow-launch`

</td>
<td>

Enables the launch command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`android-intent:deny-launch`

</td>
<td>

Denies the launch command without any pre-configured scope.

</td>
</tr>
</table>
