EmberHub — 解压即运行便携版
==========================

1. 把本文件夹解压到任意位置（如 D:\EmberHub）。
2. 双击 EmberHub.exe 运行。
3. 首次按 F1 打开设置：填 OpenList 地址 / 账号 / 资源源，保存后自动扫描游戏库。

数据位置
- 便携：下载的 ROM / 模拟器与缓存默认写在 exe 同级目录：
  Roms\  Emulators\  .cache\  logs\
- 卸载 = 直接删除整个文件夹（设置页也可改到别的下载目录）。

依赖
- Windows 10/11。需要 WebView2 运行时（Win11 与较新 Win10 一般自带）；
  若提示缺少，装一下「Microsoft Edge WebView2 Runtime」即可。

快捷键
- F1 设置 / F5 重扫 / F11 全屏 / Esc 逐层关闭。
